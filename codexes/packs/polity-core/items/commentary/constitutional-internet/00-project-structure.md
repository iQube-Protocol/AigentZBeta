# Constitutional Internet Book Project — Polity Core Structure

**Status:** Proposed project structure — governing map for the book project
**Work:** *The Constitutional Internet: The Last Human Frontier* (Dele Atanda)
**Companion record:** CI-CC-001 — The Constitutional Internet Book Constitution (`ci-cc-001-book-constitution`)

## Canonical home

The canonical project lives in **Polity Core** because it contains constitutional
doctrine, source lineage, rulings, implementation evidence, and publication state.

Qriptopian renders and distributes the public cultural expression. It does not
become the canonical source of doctrine or manuscript state.

## Qriptopian relationship

Qriptopian exposes:

- serialized chapters and extracts;
- public essays;
- interviews and press materials;
- interactive Constitutional Plates;
- audiovisual material;
- reader annotations and discussion;
- journalism and Constitutional Media experiments;
- and the public threshold into the Living Edition.

The canonical relationship is:

> Polity Core preserves constitutional source and state.
> Qriptopian carries the work into public culture.

## Evidence graph

The project exposes this graph:

> Manuscript passage
> → Doctrine
> → Constitutional invariant
> → Implementation
> → Test
> → Receipt or demonstration
> → Plate
> → Living reader experience

Every link must preserve provenance and state.
