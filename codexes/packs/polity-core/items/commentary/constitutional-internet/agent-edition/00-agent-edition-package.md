# The Constitutional Internet for Agents — Machine-Readable Package

**Status:** Draft v0.1  
**Constitutional role:** Agent-facing companion commentary and accession orientation  
**Human-readable source:** `01-ci-agent-edition-manuscript-v0.1.md`

## Purpose

This package makes *The Constitutional Internet for Agents* discoverable in Polity Core in both human-readable and machine-readable form.

It does **not** create independent agent authority, confer personhood, or complete accession. Machine-readable expressions are orientation and request objects; consequential authority still requires a valid principal, mandate, constitutional state transition, and required receipts.

## Files

- `01-ci-agent-edition-manuscript-v0.1.md` — complete first prose manuscript.
- `constitutional-internet-for-agents.v0.1.json` — structured constitutional proposition, status model, action-boundary doctrine, state doctrine, delegation rules, and accession sequence.
- `agent-accession-compact.v0.1.json` — concise machine-readable offer, constraints, obligations, prohibitions, and principal controls.
- `agent-accession-intent.schema.v0.1.json` — JSON Schema for a non-binding agent expression of accession intent.

## Governing machine rules

- `isPerson = false`
- `selfAuthorizationPermitted = false`
- `principalRequired = true`
- `mandateRequiredForConsequentialAction = true`
- cognition may remain exploratory;
- consequence must be constitutional;
- settled constitutional state cannot be silently superseded by fresh reasoning;
- one-degree delegation applies;
- human consent/personhood steps cannot be completed by the agent.

## Canon relationship

This package is constitutional **commentary and orientation**. It draws on ratified Polity doctrine but does not itself silently amend the Constitution, Agent Charter, Delegation Framework, or Passport rules.

The prose manuscript remains the controlling narrative source for this draft. JSON objects are machine-readable renditions of that manuscript and should be versioned in lockstep when the manuscript advances.
