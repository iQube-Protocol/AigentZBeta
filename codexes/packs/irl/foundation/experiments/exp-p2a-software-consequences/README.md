> engineering outcomes?"

## Outcomes — the operator's lists, PENDING OPERATOR PROTOCOL

Recorded from the ruling. No operational definition, instrument, scale, or endpoint hierarchy is
stated here; those are protocol decisions.

| Class | Ruling's list |
|---|---|
| Primary | task completion correctness |
| Secondary | implementation effort · review effort · defects · regressions · repair cost · time-to-acceptance · architectural consistency |
| New, P3-derived | representational accessibility · assumption generation · representational fidelity |

The third row is what P3 adds to a consequence experiment that monolithic P2 could not have had:
the first two measure what the work produced, the third measures the representation that produced
it. Their measurement runs through the RSS-001 machinery named in the shared framework §3.

## Experimental arms — the ruling's labels, PENDING OPERATOR PROTOCOL

| Arm | Ruling's label |

| B | content-matched structured specification |

construction, assignment, counterbalancing, blinding, or contrasts — including which contrast is
