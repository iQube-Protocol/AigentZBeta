## Admissibility precondition — RSS-001

Every representation entering EXP-P2B must first pass **RSS-001 certification**; only a certified
representation is admissible into the consequence experiment. This is the change the ruling calls
the biggest methodological improvement, and it applies to P2B with particular force: the prior
protocol (§9) *asserted* information equivalence through auditor comparison, where RSS-001
*certifies* it through a content-mapping matrix and a measured back-translation audit. The gate,
with its RSS-001 section citations, is §3 of the shared constitutional framework. The standard:
[`../exp-p3-representation-of-structural-invariants/03_RSS-001_representation-science-standard.md`](../exp-p3-representation-of-structural-invariants/03_RSS-001_representation-science-standard.md).

Nothing is certified yet — the ⟦ ⟧ parameter freeze RSS-001 requires of an adopting experiment is
part of the pending protocol.
