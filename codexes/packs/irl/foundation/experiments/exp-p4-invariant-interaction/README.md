# EXP-P4 — Invariant Interaction (RESERVED — not yet designed)

**Invariant Research Lab (IRL) · Validation Programme series (P1 / P2 / P3 / P4)**
**Status: RESERVED — designation held, protocol not yet shaped**
**Hypothesis class: Interaction**

> **This is a reservation, not a design.** It exists so the EXP-P4 designation cannot be taken by
> another experiment before the interaction protocol is written, and so the Laboratory shows the
> fourth slot honestly as reserved rather than silently absent. Nothing here is a protocol, a
> prediction, or a claim. It must not be sent to external reviewers as an experimental brief, and
> no result may be attributed to EXP-P4 until a ratified protocol replaces this file.

## Why the designation is reserved

Operator ruling, 2026-07-27: **EXP-P1 / P2 / P3 / P4 are reserved for the four strategically core
experiments that cover the breadth of invariant research.** Other designs — however valuable —
take EXP-0NN numbers. Two designs that previously occupied P2 and P3 were renumbered the same day
to free those slots (see *Renumbering record* below).

The four core questions, as the series' own briefs state them:

| Designation | Question | Hypothesis class |
|---|---|---|
| EXP-P1 | Can reasoning be compressed into structural invariants? | Compression |
| EXP-P2 | Do invariant-guided workflows improve consequential outcomes? | Consequence |
| EXP-P3 | Does representational substrate materially affect reasoning? | Representation |
| **EXP-P4 (Reserved)** | **Do structural invariants exhibit interaction or field-like behaviour?** | **Interaction** |

## Provenance of the reservation

EXP-P4 is not invented here. It is named in the operator-supplied P3 material staged at
`../_source/2026-07-26_exp-p3-spec-record-implbrief_source.md`, which reserves it explicitly and
records **why** it was deferred rather than folded into P3:

> *"Interaction, interference, resonance and field behaviour concern properties of structural
> invariants themselves rather than their representation. Accordingly these hypotheses were
> separated into a future experiment."*

And the deferred-research note, verbatim:

> *"Reserved for future investigation — EXP-P4: interaction between structural invariants.
> Candidate topics: invariant interaction; interference; resonance; attractor behaviour; field
> dynamics; representational evolution; hybrid invariant systems; neo-hieroglyphic
> representations. None forms part of P3."*

**The candidate topics above are candidates, not scope.** Selecting among them is the first act of
designing P4, and none of them is committed by this reservation.

## Epistemic status

Every claim EXP-P4 would test is an **empirical hypothesis** about the world, so nothing in this
area enters the invariant register as `canonical` on the strength of a design. The relevant
governing invariants remain `proposed` — notably `inv.reasoning.323` (intelligence as a property
of fields), which an interaction experiment bears directly on and which must stay `proposed` until
evidence exists. Reserving a designation is not evidence.

## What has to happen before this file is replaced

1. Scope selected from the candidate topics — one question, not the list.
2. Protocol authored to the same standard as the P3 set (brief · protocol · statistical analysis
   plan · implementation guide · internal research record), reusing **RSS-001**
   (`../exp-p3-representation-of-structural-invariants/03_RSS-001_representation-science-standard.md`)
   where it applies — it is a reusable standard, not a P3-only artifact.
3. Predictions pre-registered before any run.
4. Operator ratification, then external review alongside the series.
