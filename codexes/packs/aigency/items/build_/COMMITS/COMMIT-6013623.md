## Commit Message

```
fix Track 2 v2 state machine: frozen-generation scoping, false provenance gate, same-tab deep-link, acquisition bridge

Four defects in the Research Copilot / Track 2 loop, all root-caused to the
absence of a successor-crystal identity distinct from frozen vP1:

- loadTrack2ProgrammeState now excludes promoted candidates already resolved
  into the frozen predecessor's manifest (via latestFrozenCrystalArtifact +
  buildFrozenCrystalManifest) from BOTH Stage 4's promoted count and the
  Stage 5-7 cohort, so vP1's own historical promotions stop masquerading as
  v2 construction work. No vP1 row is deleted or relabeled.
- firstPendingDecision no longer treats a partially-complete stage with an
  empty remedies list (an already-resolved historical exclusion, not live
  work) as a pending human gate — closes the false "Classify Provenance"
  gate. The ratified partially-complete status derivation is untouched.
- InvariantExperimentLab now reacts to a live codex:navigate-tab dispatch
  while already mounted, re-consuming the deep-link mailbox instead of
  relying solely on a remount that codex:navigate-tab's own same-tab no-op
  guard prevents — closes the Copilot CTA landing on EXP-001.
- buildAcquisitionPendingDecision turns an applicable targeted acquisition
  brief into one correctly-named, correctly-routed pending decision (Stage 1,
  never Classify Provenance) instead of a dead-end report with no CTA. It
  never runs discovery itself.
```

## Body

Four defects in the Research Copilot / Track 2 loop, all root-caused to the
absence of a successor-crystal identity distinct from frozen vP1:

- loadTrack2ProgrammeState now excludes promoted candidates already resolved
  into the frozen predecessor's manifest (via latestFrozenCrystalArtifact +
  buildFrozenCrystalManifest) from BOTH Stage 4's promoted count and the
  Stage 5-7 cohort, so vP1's own historical promotions stop masquerading as
  v2 construction work. No vP1 row is deleted or relabeled.
- firstPendingDecision no longer treats a partially-complete stage with an
  empty remedies list (an already-resolved historical exclusion, not live
  work) as a pending human gate — closes the false "Classify Provenance"
  gate. The ratified partially-complete status derivation is untouched.
- InvariantExperimentLab now reacts to a live codex:navigate-tab dispatch
  while already mounted, re-consuming the deep-link mailbox instead of
  relying solely on a remount that codex:navigate-tab's own same-tab no-op
  guard prevents — closes the Copilot CTA landing on EXP-001.
- buildAcquisitionPendingDecision turns an applicable targeted acquisition
  brief into one correctly-named, correctly-routed pending decision (Stage 1,
  never Classify Provenance) instead of a dead-end report with no CTA. It
  never runs discovery itself.
