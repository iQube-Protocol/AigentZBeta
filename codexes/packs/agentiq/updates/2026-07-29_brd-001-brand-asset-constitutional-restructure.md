## How the size ladders were built (and what wasn't fabricated)

No vector source rasterized: `metame.ai` is a genuine CorelDRAW-exported vector PDF, but both
available renderers in this environment (`pdftoppm`, `pdftocairo`, poppler-utils) produced a
blank page — a spot-color/ICC interaction, not a corrupt file. Rather than force a workaround,
every PNG in `metaMe/` and `iQube/*/` was generated by **resizing the existing rasters**:
`metame.png` (already a clean transparent PNG) for the hand mark; the four colorway render PNGs
for the cube, white-keyed to transparency and square-cropped to the mark's bounding box.

Two real limitations are documented in `CONSTITUTIONAL_BRAND_ASSETS.md` rather than papered over:

1. **iQube colorway PNGs lose legibility below ~128px** — they're photorealistic 3D renders, and
   the bevel/circuit detail collapses into noise at 16/32px. The doc states this plainly and
   directs small-size use (favicons, tiny badges) to the metaMe mark instead.
2. **No true SVG exists yet** for either mark, for the rasterization reason above. `favicon.ico`
   is a real multi-size ICO (16/32/48), so standard favicon usage is covered without SVG. Closing
   this gap needs a flat SVG export from the source design tool (CorelDRAW/Illustrator), not
   another automated attempt.

## Companion extension unblocked

`extension/companion-observer/manifest.json` had no `icons` field (confirmed gap from the prior
session). Now wired with the metaMe mark at 16/32/48/128px (`icons` + `action.default_icon`), and
the extension zip was rebuilt with icons included.
